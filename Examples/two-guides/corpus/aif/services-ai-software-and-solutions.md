# Use the best AI development tools

AI software and solutions

Our AI software and solutions environment gives you access to relevant software and tools needed for AI development tasks. We provide ready-to-use AI tools, inference services for AI development purposes and tools for MLOps.

The environment includes:

- **Inference services**: LUMI AI Factory provides multiple inference services. Aitta inference service hosts curated AI models for the research and development purposes. EXA4MIND Inference service is developed on efficient leveraging of HPC resources on extreme data.
- **Infrastructure for AI Agents**: The LUMI AI Factory agent environment is a containerised environment for running AI coding agents on LUMI. Currently, we provide a container for using the open-source, terminal-based OpenCode AI coding agent. The LUMI AI Factory also provides a public Model Context Protocol (MCP) server allowing AI agents to, e.g., answer questions about LUMI. There also exists multiple chat services for different national users.
- **The AI Software Environment** by LUMI AI Factory is a comprehensive, ready-to-use containerised stack for AI and machine learning workloads on the LUMI supercomputer. The environment is designed to address the complexity of deploying and maintaining AI/ML software in high-performance computing (HPC) setting.
- **Containerized workflows** are provided in LUMI to streamline AI related tasks in HPC environment. The Containerized Workflows consist of pre-built container images, custom software, pre-tested models and examples as well as documentation that can be used to kickstart the use of AI in specific types of tasks. Currently there are tools for text and image processing.
- **LUMI HPC-APIs** are provided to support AI use cases.

Later on we will release MLOps environment with MLFlow and Kubeflow.
