# Agentic AI: Beyond coding assistants and chatbots

## Event details

Location: Online

Date: 3.–5.11.2026

Time: 13:00–16:30 EET

Join us for a hands-on workshop on building AI agents step-by-step!

This is a three-day workshop on building AI agents that can act, not just answer. Over the sessions, participants build agents step by step, starting from a plain OpenAI REST API call and ending with complex multi-agent workflows using Pydantic AI. Along the way the workshop covers the full stack you need to ship agents: the components that make up an agent, how they connect, and how to run them for specific task with a limited scope.

## The topics covered include:

- LLM basics and inference: how models work at a practical level, serving models with an inference server like Aitta, and using prompt templates
- Building agents from scratch: from a single REST call to structured agentic workflows with Pydantic AI
- Components of an agent: the model, the harness, the loop, tools, MCP servers, skills, memory, and how they fit together
- Security, evaluation: what breaks when agents leave the laptop, how to evaluate them, and how to run them reliably

## Key takeaways for participants:

- Identify the main components of an AI agent (model, tools, memory, harness) and recall standard concepts such as tool calling and MCP
- Build working agents in stages, from a raw OpenAI REST API call to structured agents with Pydantic AI, and connect tools, MCP servers and memory to them
- Analyze and identify potential pitfalls when moving agents from development to production setting

## Target audience

- IT professionals, software engineers and data scientists
- Programmers curious to move out of a chat interface and integrate AI in their routine tasks
- People who have used LLM chatbots or coding assistants and want to understand how they work behind the scenes

## Prerequisites

- Prior programming experience in Python
- No prior machine learning background is required

## Agenda

2.11.2026: Pre-workshop setup with Aitta and the training environment
