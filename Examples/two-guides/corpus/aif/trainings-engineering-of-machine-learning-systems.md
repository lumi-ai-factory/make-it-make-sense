# Engineering of Machine Learning systems

## Event details

Location: CSC Training Facilities, Life Science Center, Keilaranta 14 02100, Espoo

Date: 3.12.2025

Time: 09:00-16:00 (EET)

This a one day introductory course for those wanting to create machine learning pipelines and to use machine learning operations (MLOps) practices to automate the machine learning lifecycle. MLOps aims to ensure that ML models are reliable, scalable, and can be deployed efficiently.

The course is one day intensive course on the third of December and it will be split into 50% lectures and 50% hands-on tutorials.

## Learning outcomes

The main learning goals are to get basic understanding of the MLOps best practices and how to use them to implement automated machine learning pipelines.

## Prerequisites

The prerequisites of the course are the knowledge of basic machine learning and programming skills to complete the tutorials session of the course.
