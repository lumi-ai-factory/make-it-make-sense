# LUMI AI Factory onboarding

[access the LUMI AI Factory onboarding materials here](https://lumi-ai-factory.github.io/LUMI_AIF_Onboarding/)

This onboarding guide helps you get started with the LUMI supercomputer by teaching the core skills needed to use a supercomputer and run real world AI workloads.

What you will learn:

- Run your first AI job on LUMI!
- How to access and connect to LUMI
- How to transfer data and code to LUMI
- How to work with command line tools and software modules
- How to submit, monitor, and manage AI workloads using Slurm
