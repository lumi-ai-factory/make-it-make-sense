# Introduction to Engineering of Machine Learning systems

## Event details

Location: CSC Training Facilities (room Debatti), Keilaranta 14, Espoo, Finland / Online

Date: 25.5.2026

Time: 9:00–16:00 EEST

Join this one-day introductory course for researchers, students, and industry practitioner wanting to create machine learning pipelines and to use machine learning operations (MLOps) practices to automate the machine learning lifecycle. MLOps aims to ensure that ML models are reliable, scalable, and can be deployed efficiently.

The prerequisites for the course are the knowledge of basic machine learning and programming skills to complete the tutorials session of the course. The main learning goals are to get basic understanding of the MLOps best practices and how to use them to implement automated machine learning pipelines.

The course is one day intensive course on 25.5.2026 and will start at 9:00 and end at 16:00. It will be split into 50% lectures and 50% hands-on tutorials. There will also be a Zoom link for attending the lectures remotely.
