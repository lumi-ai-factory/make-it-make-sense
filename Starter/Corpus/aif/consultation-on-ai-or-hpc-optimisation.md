# Consultation on AI or HPC optimisation

*Get expert support to enhance performance or scalability of program code – whether it’s your own or third‑party software.*

## Service features

Achieving good performance and scalability in AI/HPC environments may require targeted optimisation of both code and workflows, rather than relying on default configurations. Typical challenges include inefficient use of GPUs, data pipeline and I/O bottlenecks, scaling across node, memory constraints with large AI models, and software stack and portability issues.

AI/HPC optimisation consultation provides you with tailored support for enhancing the performance or scalability of applications running on the LUMI supercomputer. Our AI Factory experts help you analyse, profile and optimise your program code to ensure efficient utilisation of computational resources, saving you time and effort.

The program code to be optimised can either be developed by you or it can also be some third-party application used in AI research or development.
